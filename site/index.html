Differentiable particle filtering with optimal transport

Can a particle filter give gradients good enough to learn a model's parameters? Benchmarked against the exact Kalman score on a linear-Gaussian model, over 100 seeds.

10xsmaller score bias than multinomial resampling (N=100)
2.6xlower score RMSE than multinomial resampling (N=100)

130xslower per filter run than multinomial (CPU, indicative)

The question

Particle filters estimate the likelihood of state-space models that have no closed form. To fit their parameters by gradient descent, we need the gradient of that estimate, but the resampling step draws discrete ancestor indices: automatic differentiation silently treats them as constants and returns a biased gradient. Corenflos et al. (ICML 2021) replace the random draw with an entropy-regularised optimal transport map, which is smooth. This page measures what that buys, on a model where the exact answer is known.

Setup

  • Model: xt = diag(θ) xt-1 + N(0, 12 I), yt = xt + N(0, 0.52 I), in 2-D, T = 100 observations, true θ = (0.8, 0.5).
  • Ground truth: the Kalman filter gives the exact log-likelihood; autograd through it gives the exact score.
  • Resampling at every step: multinomial (gradient ignores resampling), soft resampling (Karkus et al., 2018, α = 0.5), and OT resampling with ε in [0.25, 0.5, 1.0] (squared distance between particles standardised per dimension).
  • OT plans by log-domain Sinkhorn; gradients by implicit differentiation at the fixed point, checked against finite differences.

2. Learning the parameters

Adam (150 steps, learning rate 0.02, N = 50, 5 runs each) from θ = (0.1, 0.95). Contours: exact log-likelihood. Mean distance of the final iterate (average of the last 20) to the exact MLE: multinomial 0.025, soft 0.023, OT 0.040. On this model the gradient bias measured at the true parameter does not translate into worse parameters: every run of every scheme ends within 0.053 of the MLE. Better gradients did not buy better estimates here; they matter where the biased gradient points somewhere else, which this benchmark does not show.

3. A harder, nonlinear model

The univariate growth model of the original student project (y = x2/20 + noise, bimodal posterior), 100 sequences of length 50, N = 100. Paired change in RMSE against multinomial resampling: OT (ε = 0.5) -0.12 ± 0.24, not significant; OT (ε = 1) +0.35 ± 0.34, worse, consistent with a large ε averaging particles across the two modes. The 2024 claim that OT resampling tracks more accurately came from a single unseeded run and does not hold.

Limitations

  • One small model (2 parameters, d = 2) where the Kalman filter is exact; the point is a ground truth, not scale.
  • OT resampling costs O(N2) per step and many Sinkhorn iterations at small ε; here it is about 130x slower than multinomial resampling at N = 100 (CPU, shared machine, indicative only).
  • The OT estimator is biased for any fixed ε > 0: the barycentric map shrinks the particle cloud.
  • Learning runs use a fixed learning rate and few repeats; distances to the MLE are indicative.
